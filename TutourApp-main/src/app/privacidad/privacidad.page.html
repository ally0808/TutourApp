Privacidad

Tu información está segura

Tutour está diseñado para ofrecer una experiencia turística sencilla sin solicitar una cuenta de usuario.

Permiso de ubicación

La aplicación puede solicitar permiso para utilizar tu ubicación y mostrar lugares cercanos o facilitar la consulta de rutas.

Favoritos

Los lugares que guardes como favoritos se almacenan únicamente en este dispositivo.

Uso de mapas

La aplicación puede utilizar servicios de mapas para mostrar ubicaciones y facilitar la navegación hacia los lugares seleccionados.

Información

Tutour busca utilizar únicamente la información necesaria para proporcionar sus funciones y mejorar la experiencia de navegación.
